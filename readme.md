# 📨 Noti by Appekt Labs

> **In-App Notifications & Messaging SDK**  
> Ideal for **Product Updates, Feature Announcements, and Alerts**

---

### 🚀 Overview

**Noti** is a lightweight, open-source **in-app messaging and notification service** built by [Appekt Labs](https://appektlabs.com).  
It helps product teams communicate **feature releases, changelogs, and announcements** directly inside their apps through elegant **banners, modals, and widgets** — no email or push integration required.

---

### ✨ Key Features

- 🧩 **In-App Messaging:** Deliver contextual updates to users where they actually are.
- 📢 **Announcements & Product Updates:** Perfect for feature rollouts or system alerts.
- 🎨 **Customizable UI Widgets:** Plug-and-play banners, toasts, and modals.
- 🧠 **Smart Targeting:** Show messages to specific user groups, plans, or behaviors.
- ⚡ **API-Driven:** Simple REST/GraphQL APIs for message creation and delivery.
- 🔐 **Privacy First:** No tracking or intrusive analytics — just clean communication.

---

### 🏗️ Tech Stack

- **Backend:** Go (Chi) + PostgreSQL  
- **Frontend SDK:** TypeScript + React  
- **Storage:** MinIO / S3  
- **Auth:** OAuth 2.0 + JWT  
- **Deploy:** Docker Compose / Traefik / Fly.io
